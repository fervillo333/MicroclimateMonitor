# Журнал рішень (проблема → рішення)

| № | Проблема | Рішення |
|---|---|---|
| 1 | Потрібна БД без окремого сервера, що працює на Windows/Linux/macOS | SQLite через Microsoft.Data.Sqlite — один файл, без встановлення |
| 2 | Як виявляти різкі стрибки температури без ML | z-score відносно ковзного вікна (`AnomalyDetector`), поріг 3σ |
| 3 | При ідеально стабільних даних σ≈0, будь-яка дрібниця стає «аномалією» | Мінімальне σ = 0.3 (розв'язність датчика) |
| 4 | Аномальне значення спотворює середнє й σ для наступних вимірювань | Аномалії не додаються у вікно |
| 5 | Вимірювання без сповіщень (або навпаки) у БД дає неузгоджені дані | Вимірювання та його сповіщення зберігаються в одній транзакції |
| 6 | Некоректні дані датчика (NaN, 150 % вологості) ламають аналіз | `ReadingValidator` викликається перед аналізом і перед записом у БД |
| 7 | Час у SQLite немає типу; сортування рядків має збігатися з хронологічним | Час зберігається як ISO-8601 (`"O"`, UTC) — лексикографічний порядок = хронологічний |
| 8 | Тести на Windows не могли видалити файл БД (пул з'єднань) | `Pooling=False` + `SqliteConnection.ClearAllPools()` у `TestDb.Dispose` |
| 9 | Як тестувати CLI | Вивід через `TextWriter`, логіка в `CommandRunner`, `Program.cs` — тонка обгортка |
